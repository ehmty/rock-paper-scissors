# Rock Paper Scissors

## Step 1: Setup project

- create and CLONE Git repo
- create index.html and javascript.js
- link .js in .html and test log output in browser


## Step 2: Logic to get computer choice

- call getComputerChoice RETURNING computerChoice
- get a word out of an array with a randomized index between 0 and 2


## Step 3: Logic to get human choice

- select all three buttons
- handle click event for each button
- set text of clicked button to humanChoice


## Step 4: Declare global variables

- init global scope score values for computer and human to 0
- init max round to 0


## Step 5: Logic to play a single round
- Call playRound
- compare choices
- announce that round winner depending on that choices


## Step 6: Logic to play the entire game
- logic in playRound
- playing max 5 rounds
- then announce a winner depending on the higher score
